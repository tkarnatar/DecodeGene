# 🔒 Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** disclose it in a public issue. Contact the maintainers privately instead.

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `main` (latest) | ✅ |
| Tagged releases | ✅ Use the latest |

## Notes

- This project provides health education content but is **not** a medical service.
- Never commit API keys or secrets (`backend/.env` is already git-ignored).
- Dependencies are served by the official `pip` / `npm` registries; keep them up to date.

> **Disclaimer**: DecodeGene is for educational/research use only and is not a substitute for professional medical advice.
