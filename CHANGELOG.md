# 📋 Changelog

All notable changes to this project are documented here, following [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-15

### Added
- 🧬 Base engineering: FastAPI backend, Pydantic models, config module.
- 📦 Data pipeline: Open Targets / ClinVar API adapters, metaphor library, one-command pipeline.
- 🧮 Inheritance calculator for AD / AR / XR / XD patterns.
- 🩺 Doctor checklist generator.
- 📄 Genetic report plain-language translator (DeepSeek, with offline fallback).
- 🤖 Streaming AI Q&A chat (SSE).
- 🌐 Bilingual frontend (React + Vite).
- 🧪 pytest suite + CI workflow.
- 📊 20 curated gene entries.
