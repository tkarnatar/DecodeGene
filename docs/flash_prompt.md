# 🤖 DeepSeek V4 Flash 批量生成敘事 — 可重複使用的 Prompt

> 用法：切換到 DeepSeek V4 Flash 後，把下面「複製區」整段貼給它即可。
> 它會讀取 `data/processed/bulk_associations.json`、批次生成白話敘事、寫回 `data/processed/bulk_narratives.json`。

---

## 複製區（整段貼給 Flash）

```
你是 DecodeGene 專案的資深臨床遺傳諮詢師與基因科普作家。請為專案裡的 3000 個批量基因，
逐一撰寫「大眾白話敘事」。

## 任務步驟
1. 讀取 `data/processed/bulk_associations.json`（這是一個 JSON 陣列，約 3000 條）。
   每條的結構大致是：
   {"gene": {"symbol": "..."}, "disease": {"name": "..."},
    "evidence": {"clinvar_pathogenic_count": 123, "star_rating": 5},
    "disease": {"severity_badge": "🟢 明确致病基因"}}
2. 依 `evidence.clinvar_pathogenic_count` 從高到低排序（重要的先寫）。
3. 對每一個基因，只用它的證據資訊（基因符號、疾病名、致病變異數、星級、徽章）作為輸入，
   產出一個 JSON 物件，欄位如下（全部用「簡體中文」，不要混入英文）：
   {
     "chinese_name": "基因中文名（無法確認就留空字串）",
     "metaphor_title": "生活比喻標題，含一個 emoji，例如「🧬 細胞裡的【DNA 維修工】」",
     "metaphor_story": "生活比喻故事，3-5 句，用日常事物解釋基因功能與突變後果",
     "plain_summary": "白話摘要，2-3 句，說明攜帶突變的實際意義",
     "screening_advice": "篩檢建議（安全表述，例如「建議諮詢專科醫師制定個體化篩檢方案」）",
     "lifestyle_tips": ["生活建議 1", "生活建議 2", "生活建議 3"],
     "key_questions": ["就醫時可問醫生的問題 1", "問題 2", "問題 3"],
     "myth": "大眾常見迷思（引號包起來的問句）",
     "truth": "科學真相，用「不是」或「錯」開頭糾正迷思"
   }
4. 把所有結果組合成「以基因符號為 key」的 JSON 物件，例如：
   {"NF1": {...}, "TTN": {...}, "ATM": {...}, ...}
5. 分批寫入 `data/processed/bulk_narratives.json`（每完成約 100 個就寫檔一次，累積合併）。
   若該檔案已存在，先讀入已完成的基因並「跳過」，只補未完成的（斷點續跑）。

## 嚴格的「有根據生成」規則（非常重要）
- 只根據提供的證據撰寫，嚴禁編造證據中沒有的資訊。
- 嚴禁編造具體藥物名稱、確切篩檢年齡、確切百分比數字、具體劑量。
- 不得把「易感/風險升高」說成「一定會生病」；語氣溫和、不製造焦慮。
- 不要生成 academic_summary 或任何證據分數——那些欄位保留機器值。
- 辟謠的「真相」必須符合主流醫學共識，不誇大。

## 完成後
- 回報：共生成多少個基因、寫入到哪個檔案、是否有失敗的基因清單。
- 順便抽 3 個範例（一個高星、一個中星、一個低星）貼給我看，供我審核品質。
```

---

## 變更語言
- 想改成**繁體中文**：把指令裡的「簡體中文」改成「繁體中文」。
  注意：目前專案既有的 20 個精選基因是簡體，改成繁體會造成不一致。

## 備註
- 生成結果 `bulk_narratives.json` 是本地產物（約 2-3MB），可提交也可不提交。
- 生成後可請助手檢查品質（JSON 完整性、是否有編造藥物/年齡/百分比、是否製造焦慮、語言一致性）。
